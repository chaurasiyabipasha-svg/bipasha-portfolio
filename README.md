# Bipasha Chourasiya — 3D Portfolio

A futuristic 3D portfolio starter built with React, Vite, Three.js / React Three Fiber and Framer Motion.

## 1. Install

Make sure Node.js is installed, then run:

```bash
npm install
```

## 2. Start locally

```bash
npm run dev
```

Open the localhost URL shown in your terminal.

## 3. Customize

Edit `src/main.jsx` to change:
- name and bio
- skills
- project titles/descriptions/links
- LinkedIn/GitHub
- email

Edit `src/styles.css` to change colors, spacing and typography.

## 4. Build

```bash
npm run build
```

## 5. Deploy

Push the project to GitHub and import the repository into Vercel.
Vercel will detect Vite automatically.
